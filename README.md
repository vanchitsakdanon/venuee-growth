# venuee-growth

Landing page หน้าเดียวของ Venuee Performance Marketing (Next.js App Router + TypeScript + Tailwind v4)

- แก้ข้อความ: ไฟล์ใน `app/components/`
- แก้สี/ฟอนต์/ขนาดตัวอักษร: `app/globals.css`
- แก้ลิงก์ LINE / ที่อยู่ / เวลาทำการ: `app/components/site.ts`
- รูป: วางใน `public/` (โลโก้ `public/logo.png`, badge `public/badges/`, โลโก้ลูกค้า `public/clients/`)

```bash
npm run dev     # เปิดดูในเครื่อง http://localhost:3000
npm run lint
npm run build
```
